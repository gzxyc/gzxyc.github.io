# 中国深圳华强北电子产品 — 华强北电子选品站

一个以**盈利为唯一目标**的纯静态跨境导购站，垂直定位**深圳华强北电子产品**。
站在海外访客角度设计：凸显"中国特色 + 工厂直供 + 低价高质"，全站 120 件商品 / 12 大品类 / 8 篇选购指南，
带搜索、筛选、排序和完整的联盟佣金链路。

本站不直接收款、不碰物流、不生产内容——只做展示与导购，成交在速卖通完成，你赚佣金。

## 页面结构

- `index.html` 首页：Hero + 搜索 + 3 卖点 + 12 品类 + 折扣榜 + 热销榜 + 指南 + CTA
- `category.html` 商品列表：120 件，可筛选、排序（`?c=品类ID&sort=排序`）
- `search.html` 搜索页：关键词全文搜索（`?q=关键词`）
- `product.html` 商品详情：规格、优缺点、评语、价格对比、双购买按钮（`?p=商品ID`）
- `guides.html` / `guide.html` 指南列表与正文（正文内嵌对应商品推荐）
- `about.html` 关于 + 联盟披露 + 联系方式

## 目录与职责

| 路径 | 作用 |
| --- | --- |

| `佣金配置指南.md` | **如何注册联盟、拿追踪 ID、配置佣金、提高成交率** |

## 数据维护

所有内容都在 `content/` 的 JSON 里，改完刷新即可，无需构建。
商品增减后跑一次 `python tools/gen_sitemap.py https://你的域名/` 更新站点地图。

**换成真实商品**：把速卖通在售商品的 `aliId`、`image`（图片URL）、`name`、`price`、`specs` 如实填入
`content/products.json`。字段结构照着文件里任意一条商品改即可。图片只外链不落地，加载失败会自动显示兜底图。

## 技术约束

- 纯静态、零构建、无框架、无外部依赖；所有路径相对，换域名/子目录不用改代码
- 页面由 `assets/js/app.js` 读取 JSON 渲染；`file://` 下 `fetch()` 被浏览器拦截，本地预览需起 HTTP 服务
- 图片外链 + 本地兜底：不存储、不生产图片内容
- 联盟披露与 `sponsored` 标记是海外联盟营销合规要求，**不要删**
